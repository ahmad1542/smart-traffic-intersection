# Smart Traffic Intersection

A simple 2D traffic intersection simulation made using C++ and OpenGL (FreeGLUT) for my Computer Graphics course.

The project shows how cars move through a four-way intersection while following traffic lights.

## Features

- Cars moving in four directions.
- Automatic and manual traffic lights.
- Adaptive green-light timing based on waiting cars.
- Different traffic density levels.
- Camera zooming and movement.
- Pause, resume, and simulation speed controls.
- A dashboard showing traffic information.

## Technologies

- C++
- OpenGL
- FreeGLUT
- Visual Studio

## Controls

| Key | Action |
|---|---|
| 1 / 2 / 3 | Change traffic density |
| M | Switch automatic/manual mode |
| N / E | Request North-South / East-West green in manual mode |
| Space | Pause / Resume |
| [ / ] | Decrease / Increase speed |
| Arrow Keys | Move camera |
| Mouse Wheel | Zoom in / out |
| C | Reset camera |
| R | Reset simulation |
| Esc | Exit |

## How to Run

1. Open the project in Visual Studio.
2. Make sure FreeGLUT is configured.
3. Build and run the project.

## Computer Graphics Concepts

This project uses basic 2D shapes to draw roads, cars, and traffic lights. It also uses translation, rotation, scaling, orthographic projection, and animation to create the simulation.

## Project Purpose

The goal of this project is to practice Computer Graphics concepts by building a simple interactive traffic simulation.
